I build things for the browser and wire up networks for fun.

Most days I'm pushing pixels — making layouts that look clean on a big screen and still hold up on a cheap phone. The rest of the time I'm deep in Cisco Packet Tracer, carving out VLANs, setting up OSPF, and staring at `Request timed out` until I find the one wrong subnet mask that broke everything.

I learn by doing, so most of what's here started as "let's see if this works." Some of it actually did — check it out at **[nopalll.web.id](https://nopalll.web.id)**. Got a project in mind or a network that won't ping? Hit me up.
